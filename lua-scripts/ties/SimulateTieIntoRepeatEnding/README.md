# SimulateTieIntoRepeatEnding

Simulates a tie that continues into a repeat ending. It uses a hidden, muted grace note to make the tie appear to enter the ending when a direct tie across the repeat-ending boundary is not possible.

---

リピート括弧の中へ続くタイを視覚的に再現します。リピート括弧の境界を越えてタイを直接つなげられない場合に、非表示かつ再生を抑制した装飾音符を利用して表現します。
