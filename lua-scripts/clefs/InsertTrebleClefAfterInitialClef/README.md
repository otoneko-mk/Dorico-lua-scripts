# InsertTrebleClefAfterInitialClef

Inserts a treble clef after the initial clef. This reproduces the traditional grand-staff notation in which the original clef is shown before a clef change. A hidden, muted grace note makes this placement possible.

---

最初の音部記号の後にト音記号を挿入します。大譜表の冒頭に本来のト音記号・ヘ音記号を示し、その後に音部記号の変更を置く、伝統的な浄書を再現するためのものです。非表示かつ再生を抑制した装飾音符を利用して配置します。
