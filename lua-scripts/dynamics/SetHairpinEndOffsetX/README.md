# SetHairpinEndOffsetX

Sets the "End offset X" property of selected hairpins to adjust the horizontal position of their endpoints. It is useful for extending a hairpin toward the barline at the end of a system when the hairpin continues onto the next system.

---

選択したヘアピンの「終了オフセット」プロパティを設定し、終端の水平位置を調整します。次の組段まで続くヘアピンを、現在の組段末の小節線に近づけたい場合に使用します。
