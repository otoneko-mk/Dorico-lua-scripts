# SimulateSlurIntoRepeatEnding

Simulates a slur that continues into a repeat ending. It uses a hidden, muted grace note to create the appearance of a slur entering the ending when the slur cannot be drawn directly across the repeat-ending boundary.

---

リピート括弧の中へ続くスラーを視覚的に再現します。リピート括弧の境界を越えてスラーを直接つなげられない場合に、非表示かつ再生を抑制した装飾音符を利用して表現します。
