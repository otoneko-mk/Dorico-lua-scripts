# RespellPitches
Respells the selected notes enharmonically.

- **RespellWithSharps**: Rewrites flat-based notes as sharps.
- **RespellWithFlats**: Rewrites sharp-based notes as flats.
- **RespellWithNaturals**: Rewrites double sharps or double flats as naturals.

---

選択した音符を異名同音に書き換えます。

- **RespellWithSharps**：フラット系をシャープに書き換える。
- **RespellWithFlats**：シャープ系をフラットに書き換える。
- **RespellWithNaturals**：ダブルシャープやダブルフラットをナチュラルに書き換える。
