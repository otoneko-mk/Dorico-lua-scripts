# AddProlongedSoundMarkToSecondTiedNote

Adds the Japanese prolonged sound mark ("ー") as a lyric to the second note of a tied pair. This allows the mark to appear beneath the later note even when the notes are connected by a tie.

---

タイでつながれた2つの音符のうち、後ろの音符に長音符号（「ー」）を歌詞として入力します。タイを維持したまま、後ろの音符の下に長音符号を表示したい場合に使用します。
