# Dorico-lua-scripts

[[日本語]](README-ja.md)

A collection of Dorico macros (Lua scripts) built to automate repetitive tasks, achieve complex notation that's tricky to input by default, and bring in handy features from other notation software.

## Download

[Latest Release](https://github.com/otoneko-mk/Dorico-lua-scripts/releases/latest)

## Installation

### Windows

`%APPDATA%\Steinberg\Dorico 6\Script Plug-ins`

### macOS

`~/Library/Application Support/Steinberg/Dorico 6/Script Plug-ins`

## Tested Environment

- Dorico: 6.2.40.6378
- OS: Windows 11
