# Dorico-lua-scripts

[[English]](README.md)

Doricoのマクロ（Luaスクリプト）集です。操作の自動化や、標準機能では入力が難しい記譜の再現、他の楽譜作成ソフトウェアの機能の実装を目的としています。

## ダウンロード

[最新のリリース](https://github.com/otoneko-mk/Dorico-lua-scripts/releases/latest)

## インストール

### Windows

`%APPDATA%\Steinberg\Dorico 6\Script Plug-ins`

### macOS

`~/Library/Application Support/Steinberg/Dorico 6/Script Plug-ins`

## 動作確認環境

- Dorico: 6.2.40.6378
- OS: Windows 11
